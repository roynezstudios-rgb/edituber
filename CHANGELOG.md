# Changelog

Todos los cambios relevantes de EDITuber se documentan aquí. El proyecto usa versionado semántico.

## 0.2.0 — 2026-08-04

- Web Lab local con persistencia en IndexedDB, grabación acumulativa y edición de audio.
- Estados de avatar de 1, 2 y 4 imágenes e importador ZIP de personajes.
- Timeline con emociones, cortes, eliminación, deshacer y zoom.
- Movimiento global, rebote al hablar, ciclo de boca, parpadeo y transiciones deterministas.
- Documento portable autocontenido con proyecto, avatar, envolvente y audio base64.
- API local asíncrona para validar, renderizar, consultar y descargar MP4.
- Distribución reproducible mediante Docker y scripts de inicio local.
- CI de formato, tipos, pruebas, compilación, seguridad y render de humo.
- Persistencia confirmada en IndexedDB antes de anunciar cortes o deshacer como terminados.

## 0.1.0

- Primer corte estable del motor determinista, CLI, contratos y Web Lab.
